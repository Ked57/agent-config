Welcome. In this walkthrough, I'll show you how to review and approve a pull request on GitHub from start to finish. First, let's head over to the repository where the pull request is waiting for your review. You'll find the pull request tab near the top of the page. Go ahead and click on that. Here's where all the open pull requests live. Choose the one you'd like to review from this list. To see what's actually changed in the code, we'll switch over to the files changed tab. When you're ready to provide your feedback, look for the review changes button over on the right side. You've got a few options here. If you just want to leave some notes without formally approving, choose comment. To approve the pull request, select the approve option. You can also include a message if you'd like. Alternatively, if the code needs some work before it's ready, you can choose request changes instead. Once you've made your selection, click submit review to send your approval through. Perfect. You now know how to review and approve pull requests. Feel free to run through this again anytime you need a refresher.
